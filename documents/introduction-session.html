01What is Information Security?

Information security (infosec) is the practice of protecting data from unauthorized access, modification, misuse, or disruption, and limiting the damage when something does go wrong. "Data" can be digital (a database) or physical (printed blueprints), and even knowledge in people's heads.

It's a huge field with many paths, for example:

  • Network & infrastructure security
  • Application (web/mobile) security
  • Security testing / penetration testing
  • Digital forensics
  • Incident detection & response (SOC)
  • Auditing, governance & business continuity

02Risk Management

Security can't block the business from working. Organizations balance protection and productivity using a risk management process, a cycle that never really ends:

Why pentesters careTo rate a vulnerability correctly (low / medium / critical), you must understand the business risk behind it, not just the technical bug.

03Red Team vs. Blue Team

Red Team: the attackers

Play the role of a real adversary to find weaknesses before criminals do.

  • Penetration testing
  • Social engineering & phishing
  • Adversary emulation

Blue Team: the defenders

Strengthen and protect the organization. Most infosec jobs are here.

  • Monitoring & incident response
  • Writing policies, hardening systems
  • Running security tools (SIEM, EDR…)

04What Does a Pentester Do?

A penetration tester is hired (with written permission!) to find risks in a company's systems: vulnerable services, exposed data, misconfigurations. A good tester then explains how to reproduce each issue and how to fix it.

Assessment typeGoal
White-box pentestFull information given; find as many vulnerabilities as possible in the scope.
Phishing assessmentTest employees' security awareness.
Red team engagementEmulate a specific real-world attacker against a scenario.
Golden ruleNever test a system you don't own or don't have explicit written permission to test. Practice only on legal labs (Hack The Box, TryHackMe, your own VMs).

05Setting Up Your Lab

We attack from a virtual machine (VM), never directly from our main OS. A hypervisor is the software that runs VMs:

  • Free desktop options: VirtualBox, VMware Workstation (now free), Hyper-V (Windows)
  • Bare-metal / server: Proxmox, VMware ESXi

ISO vs. OVA

Choosing a Distro

Pentest distros are Linux systems pre-loaded with tools. The two most common are Parrot Security OS and Kali Linux (both Debian-based). Pick one; the skills are the same. Over time you'll build your own list of "must-have" tools.

A very technical but disorganized tester will struggle. Good notes and a clean folder structure pay off in every career path.

Folder Structure

Keep one folder per client/box, with subfolders for everything you collect:

Note-Taking Tools

07Connecting with a VPN

A VPN (Virtual Private Network) creates an encrypted tunnel over the internet into a private network, so you can reach internal machines as if you were plugged in on-site (like an employee working from home).

Commercial VPNs ≠ anonymity

Services like NordVPN hide your IP from the websites you visit and protect you on hostile Wi-Fi (airports, cafés). But the provider can still see and log your traffic. A VPN never makes illegal activity safe.

Connecting to the HTB Lab

Treat lab networks as hostileOther players are on the same network. Connect only from a VM, don't keep personal or client data on it, and don't run open services (e.g. SSH with password login).
Ba7rzz@htb[/htb]$ sudo openvpn user.ovpn
...
Initialization Sequence Completed    # ← connected!
  • sudo: run as root (admin)
  • openvpn: the VPN client
  • user.ovpn: your personal VPN config/key, downloaded from HTB

Verify the connection: a new tun0 interface appears with your lab IP.

Ba7rzz@htb[/htb]$ ip a show tun0        # or: ifconfig tun0
tun0: <POINTOPOINT,MULTICAST,NOARP,UP,LOWER_UP> mtu 1500
    inet 10.10.14.2/23 scope global tun0

08Common Terms

What is a Shell?

A shell is the program that takes your typed commands and passes them to the operating system. On Linux it's usually Bash; on Windows, cmd.exe or PowerShell.

In hacking, "getting a shell" means we exploited the target and can now run commands on it as if we were sitting in front of it.

Shell typeHow it works
Reverse shellThe target connects back to a listener on our machine. Most common, since outbound traffic is rarely blocked.
Bind shellThe target opens ("binds") a port and waits; we connect to it.
Web shellA script uploaded to a web server that runs commands sent through the browser (e.g. via a file-upload bug).

What is a Port?

If a server is a house, its ports are the doors. Each running service (website, SSH, file share…) listens behind its own numbered door. An open, badly-secured door is a way in.

There are two protocols, each with 65,535 ports:

What is a Web Server?

A web server (Apache, Nginx, IIS…) receives HTTP requests from browsers, passes them to the web application, and sends back the response. It usually listens on port 80 (HTTP) or 443 (HTTPS).

OWASP Top 10 (2025)

OWASP publishes the most critical web application risks. It's the starting checklist for most web security tests. The current edition is 2025 (replacing the 2021 list):

09Basic Tools

SSH, Netcat, tmux and Vim aren't "hacking tools", but you'll use them every single day.

SSH: Secure Shell

An encrypted protocol (port 22) for logging in to remote machines. Authenticate with a password or an SSH key pair. If we find credentials or a private key during a test, SSH gives us a stable, full shell on the target.

Ba7rzz@htb[/htb]$ ssh bob@10.10.10.10
bob@10.10.10.10's password: *********
bob@remotehost:~$

Netcat (nc)

The "Swiss-army knife" of networking: connect to any TCP/UDP port and talk to whatever is listening. Mainly used to catch reverse shells and for banner grabbing (asking a service to identify itself):

Ba7rzz@htb[/htb]$ nc 10.10.10.10 22
SSH-2.0-OpenSSH_8.4p1 Debian-3     # the service told us what it is and its version
Ba7rzz@htb[/htb]$ nc -lvnp 4444                # listen for a reverse shell on port 4444

tmux: terminal multiplexer

Run many terminals inside one window: a scan in one pane, notes in another, a listener in a third. Install with sudo apt install tmux -y, then start with tmux.

Every command starts with the prefix Ctrl + B, release, then press the key:

Prefix, then…Action
cNew window
0 1 …Switch to window #
%Split left | right
"Split top / bottom
←↑→↓Move between panes
dDetach (keeps running)

Vim: keyboard-only text editor

Vim (or vi) is installed on almost every Linux server, so you can edit files even on a machine you just broke into. Open a file with vim /etc/hosts. Vim has modes; that's the only "trick":

10Service Scanning with Nmap

Now we start exploring a target. A service is a program on a machine that does something useful for others (web server, file share, remote login). We look for services that are misconfigured or vulnerable, then try to make them do something unintended.

Checking 65,535 ports by hand is impossible, so we use Nmap (Network Mapper).

Basic scan

With no options, Nmap scans the 1,000 most common TCP ports:

Ba7rzz@htb[/htb]$ nmap 10.129.42.253

Nmap scan report for 10.129.42.253
Host is up (0.11s latency).
Not shown: 995 closed ports
PORT    STATE SERVICE
21/tcp  open  ftp
22/tcp  open  ssh
80/tcp  open  http
139/tcp open  netbios-ssn
445/tcp open  microsoft-ds
ColumnMeaning
PORTPort number / protocol (TCP by default)
STATEopen = service listening · closed = nothing there · filtered = a firewall is blocking/hiding it
SERVICENmap's guess based on the port number only. Not confirmed yet!

Detailed scan

Ba7rzz@htb[/htb]$ nmap -sV -sC -p- 10.129.42.253

PORT    STATE SERVICE     VERSION
21/tcp  open  ftp         vsftpd 3.0.3
| ftp-anon: Anonymous FTP login allowed (FTP code 230)
|_drwxr-xr-x    2 ftp      ftp          4096 Feb 25 19:25 pub
22/tcp  open  ssh         OpenSSH 8.2p1 Ubuntu 4ubuntu0.1 (Ubuntu Linux; protocol 2.0)
80/tcp  open  http        Apache httpd 2.4.41 ((Ubuntu))
|_http-title: PHP 7.4.3 - phpinfo()
139/tcp open  netbios-ssn Samba smbd 4.6.2
445/tcp open  netbios-ssn Samba smbd 4.6.2
Service Info: OSs: Unix, Linux
FlagWhat it does
-sVVersion detection: talks to each service to find its name and exact version
-sCRuns Nmap's default scripts for extra info (e.g. "anonymous FTP allowed")
-p-Scan all 65,535 ports (slower, but nothing hidden is missed)
-p21,80Scan only specific ports
--script <name>Run a specific Nmap script
Read the output like a pentester
  • OS is Ubuntu Linux; versions can be searched for known vulnerabilities.
  • Anonymous FTP is allowed → we should log in and look around.
  • The web page title is phpinfo(), a test page leaking server details.
  • SMB (139/445) is open → check for accessible file shares.
Quick OS hintPort 3389 (RDP) or 445 alone usually means Windows; port 22 (SSH) usually means Linux. These are hints, not proof.

11Enumerating Services

Banner Grabbing

Many services announce their name and version as soon as you connect. Grab it manually with Netcat, or with Nmap across a whole network:

Ba7rzz@htb[/htb]$ nc -nv 10.129.42.253 21
(UNKNOWN) [10.129.42.253] 21 (ftp) open
220 (vsFTPd 3.0.3)

Ba7rzz@htb[/htb]$ nmap -sV --script=banner -p21 10.10.10.0/24

FTP: anonymous login

Nmap told us anonymous login is allowed. Username anonymous, any (or empty) password:

Ba7rzz@htb[/htb]$ ftp -p 10.129.42.253
220 (vsFTPd 3.0.3)
Name (10.129.42.253:user): anonymous
230 Login successful.

ftp> ls
drwxr-xr-x    2 ftp      ftp          4096 Feb 25 19:25 pub
ftp> cd pub
ftp> ls
-rw-r--r--    1 ftp      ftp            18 Feb 25 19:25 login.txt
ftp> get login.txt          # download the file
226 Transfer complete.
ftp> exit

Ba7rzz@htb[/htb]$ cat login.txt
admin:ftp@dmin123                  # credentials! 🎯

One misconfiguration (anonymous access) + one careless file = credentials we can try on other services.

SMB: Windows file shares

SMB (ports 139/445) lets machines share folders over the network. Shares often contain sensitive files, and old SMB versions have famous critical bugs (e.g. EternalBlue, used by WannaCry). Here the target runs Samba, the Linux implementation of SMB.

List the shares with smbclient (-L = list, -N = no password):

Ba7rzz@htb[/htb]$ smbclient -N -L \\\\10.129.42.253

    Sharename       Type      Comment
    ---------       ----      -------
    print$          Disk      Printer Drivers
    users           Disk                      # non-default → interesting
    IPC$            IPC       IPC Service

As a guest we get NT_STATUS_ACCESS_DENIED. With credentials found elsewhere (bob:Welcome1):

Ba7rzz@htb[/htb]$ smbclient -U bob \\\\10.129.42.253\\users
Enter WORKGROUP\bob's password:

smb: \> ls
  bob                    D        0  Thu Feb 25 16:42:23 2021
smb: \> cd bob
smb: \bob\> ls
  passwords.txt          N      156  Thu Feb 25 16:42:23 2021
smb: \bob\> get passwords.txt

SNMP: device management

SNMP (UDP port 161) is used to monitor and manage network devices like routers, switches, printers and servers. Clients authenticate with a community string, which works like a shared password.

Why it's interesting for us:

  • Many devices still use the default community strings public (read) and private (read/write).
  • In v1 and v2c the community string travels in plaintext. Know it and you're in. Only v3 added authentication and encryption.
  • SNMP can leak a lot: software versions, network interfaces, routes and running processes. Process arguments sometimes contain passwords, and people reuse passwords on other services.

Query a single value (here, the hostname) with the public string:

Ba7rzz@htb[/htb]$ snmpwalk -v 2c -c public 10.129.42.253 1.3.6.1.2.1.1.5.0
iso.3.6.1.2.1.1.5.0 = STRING: "gs-svcscan"      # public works → we can read data

Ba7rzz@htb[/htb]$ snmpwalk -v 2c -c private 10.129.42.253
Timeout: No Response from 10.129.42.253     # wrong string → no answer
PartMeaning
-v 2cSNMP version to use
-c publicCommunity string to try
1.3.6.1.2.1.1.5.0OID: the "address" of one value (this one is the hostname). Leave it out to dump everything.

Don't know the string? Brute-force it with onesixtyone and a wordlist of common community strings (e.g. the dict.txt in its repo):

Ba7rzz@htb[/htb]$ onesixtyone -c dict.txt 10.129.42.254
Scanning 1 hosts, 51 communities
10.129.42.254 [public] Linux gs-svcscan 5.4.0-66-generic #74-Ubuntu SMP ... x86_64
RememberSNMP is UDP. A default nmap scan only checks TCP, so you'll miss it. Use sudo nmap -sU -p161 <ip>.
The lessonHacking is rarely one magic exploit. It's usually chaining small findings: an open port → a misconfiguration → a file → credentials → more access.

12Recap & Cheat Sheet

  • Infosec protects Confidentiality, Integrity, Availability.
  • Red team attacks to find weaknesses; blue team defends. Always get permission.
  • Work from a VM, stay organized, take notes in Markdown.
  • A port is a door to a service; TCP is reliable, UDP is fast.
  • Workflow: scan → identify → enumerate → exploit.
